# pg-ledger-mcp 2.1.0

## English

### Summary

2.1.0 is a minor release that overhauls the Admin Web (`ledger-admin-web.jar`) user interface and operational ergonomics while preserving every existing MCP tool contract, database schema, security header, and single-JAR deployment model. Because it adds substantial user-facing console capabilities without breaking any API, schema, or client contract, the minor version increases from `2.0.2` to `2.1.0`.

### Breaking changes

There are no breaking changes in this release. Existing MCP clients, client hooks, database schemas (`V1` through `V11`), configuration files, and JSON API clients continue to work without modification.

### Migration

1. Build the `2.1.0` jars with `./gradlew assemble` (no test database required) or obtain the release build.
2. Back up the currently installed jars before replacing them so rollback is a single file copy and service restart.
3. Re-run `deploy/install.sh` (Linux) or `deploy\install.cmd` (Windows) with the `2.1.0` jars directory and existing options; no new database migration runs because the schema remains at `V11`.
4. Verify both `/healthz` endpoints (`127.0.0.1:8765/healthz` and `127.0.0.1:8865/healthz`) return `UP` and sign in to the Admin Web to confirm the updated console loads cleanly.
5. To roll back, restore the backed-up `2.0.2` jars and restart `pg-ledger-mcp` and `pg-ledger-mcp-admin`.

### New

- **Semantic design system and Light/Dark themes**: Added `tokens.css` and rewrote `admin.css` with WCAG AA contrast tokens, automatic system theme detection, and a persistent manual toggle (`pgledger.theme`) in the top utility bar.
- **3-domain application shell and responsive navigation**: Added a fixed left sidebar grouped into Work & Monitoring, Governance & Access, and System & Security, a sticky utility topbar, and a keyboard-accessible mobile slide-out drawer (`Escape` close and focus restoration) with `.table-wrap` horizontal scrolling.
- **Progressive Vanilla JS interactions (`admin-ui.js`)**: Added clipboard copy buttons with polite toast feedback, a 3-tab Grants hub (`Session grants`, `Bearer tokens`, `Session keys`) with row-to-form prefill (never auto-submitting) and UTC expiry presets (`+7d`, `+30d`, `+90d`, none), Codes group filter pills and edit prefill, and History JSON diff rendering.
- **HTML form validation error recovery**: Browser HTML POST requests (`Accept: text/html`) that trigger a 4xx domain error re-render the form page with an inline danger alert and preserved inputs, while JSON clients (`Accept: application/json`) continue to receive `ProblemDetail` responses unchanged.
- **UI regression coverage (`UiOverhaulTest`)**: Added automated MockMvc tests `UI-01` through `UI-05` verifying the app shell, overview drilldowns, filter reset, history entity deep-links, HTML form recovery versus JSON `ProblemDetail`, and redirect flash feedback.

### Changed

- **Overview, list, detail, and governance templates**: Overhauled all 18 Thymeleaf templates with clickable KPI/attention/distribution drilldowns, filter bars with conditional reset links, 2-column detail layouts, history entity deep-links, a 3-step passkey enrollment stepper, and 2-column driver comparison cards.
- **Passkey interaction feedback (`passkey.js`)**: Added busy/double-submit locking (`aria-busy`), user-friendly cancellation handling (`NotAllowedError` and `AbortError`), and automatic scroll/focus to the top status banner.
- **Korean UI copy and version alignment**: Unified Korean Admin Web messages in `admin_ko.properties` to polite formal phrasing with 100% EN/KO key parity, and aligned the Gradle build, MCP server metadata, and client hook manifests to `2.1.0`.

### Removed

No features, endpoints, CLI commands, MCP tools, or settings were removed in this release.

### Security

- Strict Content Security Policy compliance is preserved across all 18 templates with zero inline `<script>`, `<style>`, `style=`, `on*=` handlers, or external CDN requests (`ArchitectureTest`, `SecurityHeadersTest`).
- Security requirement `ADM-063` is strictly preserved: refused `/driver` submissions never echo the submitted jar path or driver class name back to HTML or JSON responses.
- Enrollment sessions holding `ROLE_ENROLL` remain restricted to passkey registration with console navigation and revoke forms hidden.

### Requirements

- Java 25 runtime (`JDK 25`) on the server host and client hook hosts.
- Existing `2.0.x` PostgreSQL database (schema `V11`) and registered JDBC driver; no additional runtime dependencies or external frontend build tools are introduced.

### Known limitations

- Automated regression tests cover MockMvc rendering, CSP headers, i18n parity, and HTTP/form contracts; live visual inspection across desktop and mobile browsers remains a manual check when host hooks block browser subagent MCP calls.

## 한국어

### 요약

2.1.0은 기존 MCP 도구 계약, 데이터베이스 스키마, 보안 헤더, 단일 JAR 배포 모델을 그대로 유지하면서 관리 웹(`ledger-admin-web.jar`)의 사용자 인터페이스와 운영 편의성을 전면 개편한 마이너 릴리스입니다. API, 스키마, 클라이언트 계약을 깨지 않고 사용자 대면 콘솔 기능을 대폭 추가했으므로 부 버전을 `2.0.2`에서 `2.1.0`으로 올렸습니다.

### 호환되지 않는 변경

이 릴리스에는 호환되지 않는 변경이 없습니다. 기존 MCP 클라이언트, 클라이언트 훅, 데이터베이스 스키마(`V1`~`V11`), 설정 파일, JSON API 클라이언트는 수정 없이 그대로 동작합니다.

### 이전 절차

1. `./gradlew assemble`(시험 데이터베이스 불필요)로 `2.1.0` JAR를 빌드하거나 릴리스 빌드를 준비합니다.
2. 롤백 시 파일 복사와 서비스 재시작만으로 복구할 수 있도록 현재 설치된 JAR를 먼저 백업합니다.
3. 기존 옵션 그대로 `2.1.0` JAR 디렉터리를 지정해 `deploy/install.sh`(Linux) 또는 `deploy\install.cmd`(Windows)를 다시 실행합니다. 스키마는 `V11` 그대로이므로 추가 데이터베이스 마이그레이션은 실행되지 않습니다.
4. 두 `/healthz` 엔드포인트(`127.0.0.1:8765/healthz`, `127.0.0.1:8865/healthz`)가 `UP`을 반환하는지 확인하고 관리 웹에 로그인해 개편된 콘솔이 정상 표시되는지 확인합니다.
5. 되돌리려면 백업해 둔 `2.0.2` JAR를 복원하고 `pg-ledger-mcp`와 `pg-ledger-mcp-admin` 서비스를 재시작합니다.

### 추가

- **시맨틱 디자인 시스템 및 라이트/다크 테마**: WCAG AA 대비 토큰이 적용된 `tokens.css`를 추가하고 `admin.css`를 전면 재작성했습니다. 시스템 테마 자동 감지와 상단 유틸리티 바의 수동 전환(`pgledger.theme`)을 제공합니다.
- **3도메인 앱 쉘 및 반응형 내비게이션**: 작업·모니터링, 거버넌스·접근 제어, 시스템·보안 3개 영역으로 묶인 고정 좌측 사이드바, 상단 유틸리티 바, 키보드 접근성(`Escape` 닫기 및 포커스 복귀)을 갖춘 모바일 슬라이드 드로어와 `.table-wrap` 가로 스크롤을 추가했습니다.
- **점진적 Vanilla JS 상호작용(`admin-ui.js`)**: 복사 버튼과 토스트 알림, 행 프리필(자동 제출 없음)과 UTC 만료 프리셋(`+7d`, `+30d`, `+90d`, 없음)을 갖춘 3탭 부여 허브(`Session grants`, `Bearer tokens`, `Session keys`), 공통코드 그룹 필터 필 및 편집 프리필, 이력 JSON diff 표시를 추가했습니다.
- **HTML 폼 검증 오류 복구**: 브라우저 HTML POST 요청(`Accept: text/html`)에서 4xx 도메인 오류가 발생하면 입력값을 유지한 채 상단 오류 배너와 함께 폼 화면을 다시 렌더링합니다. JSON 클라이언트(`Accept: application/json`)는 기존과 동일하게 `ProblemDetail` 응답을 받습니다.
- **UI 회귀 시험(`UiOverhaulTest`)**: 앱 쉘, 개요 드릴다운, 필터 초기화, 이력 개체 딥링크, HTML 폼 복구 대 JSON `ProblemDetail`, 리다이렉트 플래시 배너를 검증하는 MockMvc 시험 `UI-01`~`UI-05`를 추가했습니다.

### 변경

- **개요·목록·상세·거버넌스 템플릿 전면 개편**: 18개 Thymeleaf 템플릿 전체를 클릭 가능한 KPI·주의·분포 드릴다운, 조건부 초기화 링크가 있는 필터 바, 2단 상세 레이아웃, 이력 개체 딥링크, 3단계 패스키 등록 스텝퍼, 2단 드라이버 비교 카드로 개편했습니다.
- **패스키 상호작용 피드백(`passkey.js`)**: 중복 제출 잠금(`aria-busy`), 취소 예외(`NotAllowedError`, `AbortError`) 친화적 안내, 상단 상태 배너 자동 스크롤·포커스를 추가했습니다.
- **한국어 문구 통일 및 버전 정렬**: `admin_ko.properties`의 한국어 안내 문구를 공손한 공식 문체로 통일하고 영/한 키 100% 대칭을 유지했으며, Gradle 빌드, MCP 서버 메타데이터, 클라이언트 훅 매니페스트 버전을 `2.1.0`으로 정렬했습니다.

### 제거

이 릴리스에서 제거된 기능, 엔드포인트, CLI 명령, MCP 도구 또는 설정은 없습니다.

### 보안

- 18개 템플릿 전체에서 인라인 `<script>`, `<style>`, `style=`, `on*=` 핸들러 및 외부 CDN 요청이 없는 엄격한 콘텐츠 보안 정책을 유지합니다(`ArchitectureTest`, `SecurityHeadersTest`).
- 보안 요구사항 `ADM-063`을 엄격히 유지합니다. 거부된 `/driver` 요청은 제출된 JAR 경로나 드라이버 클래스 이름을 HTML 또는 JSON 응답에 절대 되돌려 출력하지 않습니다.
- `ROLE_ENROLL` 등록 전용 세션에서는 콘솔 내비게이션과 패스키 폐기 폼이 계속 숨겨집니다.

### 요구 사항

- 서버 호스트 및 클라이언트 훅 호스트의 Java 25 런타임(`JDK 25`).
- 기존 `2.0.x` PostgreSQL 데이터베이스(스키마 `V11`) 및 등록된 JDBC 드라이버. 추가 런타임 의존성이나 외부 프론트엔드 빌드 도구는 필요하지 않습니다.

### 알려진 제한

- 자동 회귀 시험은 MockMvc 렌더링, CSP 헤더, 다국어 키 대칭, HTTP·폼 계약을 검증하며, 호스트 훅이 브라우저 서브에이전트의 MCP 호출을 차단하는 환경에서는 데스크톱·모바일 실브라우저 육안 점검을 별도로 수행해야 합니다.
